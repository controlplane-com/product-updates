# Release 2026.08.0

## Platform Updates - August 2026

- **Managed Kubernetes**
  - Upgraded managed Kubernetes to version 1.35
  - Refreshed the available AWS instance types and fixed a missing architecture on some GCP instance types
  - BYOK workloads can now set additional pod labels and a custom scheduler name

- **Workloads**
  - [Capacity AI](https://docs.controlplane.com/guides/capacity-ai) can now be enabled on cron workloads
  - Fixed deployment status incorrectly showing "deploying"

- **Cron Jobs**
  - Cron runs interrupted by preemption are now retried automatically
  - Fixed new cron executions being stopped by delete messages from a prior version of the workload
  - Unpullable cron images are now classified and surfaced more clearly

- **Virtual Machines**
  - Fixed resize, port-forward, and impersonated sessions for VM workloads
  - VM exec now honors the command, TTY, and exit code

- **Volumes**
  - Volume set volumes now record the disk type they were created on

- **Domains & DNS**
  - Fixed a client-certificate bug when it was enabled and then disabled on a domain

- **Networking**
  - Direct load-balancer workloads now keep their DNS record after a service replacement
  - Fixed BYOK external inbound CIDRs overriding the internal firewall (opt-in)

- **Monitoring & Observability**
  - Improved accuracy of the ready-replicas metric
  - Fixed rescheduled-replicas and progress-failure charts missing their initial counter events

- **MCP Server** ([docs](https://docs.controlplane.com/ai/mcp))
  - Capacity AI can now be enabled on cron workloads through the assistant
  - `update_gvc` can now edit GVC placement, and fixed truncation of long org location lists
  - Removed an inaccurate per-type Capacity AI default

- **Marketplace Templates** ([catalog](https://docs.controlplane.com/template-catalog/overview))
  - **New templates**
    - [OpenBao](https://docs.controlplane.com/template-catalog/templates/openbao)
    - [Grafana](https://docs.controlplane.com/template-catalog/templates/grafana)
    - [Listmonk](https://docs.controlplane.com/template-catalog/templates/listmonk)
    - [ToolJet](https://docs.controlplane.com/template-catalog/templates/tooljet)
    - [Docmost](https://docs.controlplane.com/template-catalog/templates/docmost)
    - [SeaweedFS](https://docs.controlplane.com/template-catalog/templates/seaweedfs)

    - [DuckDB](https://docs.controlplane.com/template-catalog/templates/duckdb)

    - [postgres-multi-location](https://docs.controlplane.com/template-catalog/templates/postgres-multi-location)

  - **Updated templates**
    - Security hardening across the catalog: sensitive credentials are now prerequisite secrets instead of chart values, and admin UIs ship private by default
    - Many templates can now be deployed into an existing GVC
    - Redis family: added a Valkey engine option (`engine: redis | valkey`) to Redis, Redis Cluster, and redis-multi-location
    - Postgres HA: Patroni metrics now reach the built-in metrics stack

- **Web Console**
  - Show effective (resolved) locations on the GVC summary and resource group pages
  - Resource groups can now be exported from the group detail page
  - Resource group pages now poll and summarize workload health
  - Platform-written tags are now shown as read-only labels in tag editors
  - Show disk type and node for volume set volumes
  - Show a retrying indicator on active cron job executions
  - Large workload and GVC environment variable lists are now virtualized and validate faster
  - Warn before saving domain edits that change DNS requirements
  - Waive stateful minimum resource ratio limits when Capacity AI is enabled everywhere
  - Added a documentation link to the workload extras editor
  - Fixed a resource group rename dead link and preserved pinned groups, the default alert email notification link, and the connect page repeatedly polling the replicas endpoint

- **CLI**
  - Released CLI version 3.16.0
  - Added `--dry-run` to resource write commands
  - Added [`--build-arg` and `--secret`](https://docs.controlplane.com/cli-reference/commands/image) to `cpln image build`
  - `cpln upgrade` now supports macOS via the published DMG, cleans up upgrade leftovers, and checks install permissions before downloading
  - Fixed upgrade install detection for Yarn Berry and Bun
