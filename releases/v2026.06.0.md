# Release 2026.06.0

## Platform Updates - June 2026

- **Workloads**
  - Added [Virtual Machine (VM) workloads](https://docs.controlplane.com/reference/workload/vm) — run full virtual machines alongside containers on the platform (custom locations only to start)
  - Clearer in-progress deployment status for standard and stateful workloads
  - Fixed autoscaling for serverless workloads referenced through location specific endpoints

- **Managed Kubernetes**
  - Added [KubeVirt](https://docs.controlplane.com/mk8s/add-ons/kubevirt) and [node-local DNS](https://docs.controlplane.com/mk8s/add-ons/node_local_dns) cluster add-ons
  - Added support for Kubernetes 1.34 and 1.35, including MutatingAdmissionPolicy
  - Expanded Azure support: added the Italy North location, refreshed pricing, hid unsupported machine sizes, and improved node pool zone validation
  - Enabled gVNIC networking on Google Cloud clusters
  - Updated the Hetzner cloud controller manager

- **Volumes**
  - Improved [volume shrink](https://docs.controlplane.com/reference/volumeset): existing data is migrated to the smaller volume, a minimum size is enforced, and orphaned volumes are prevented if a shrink fails

- **Cron Jobs**
  - Cron executions that fail at admission are now retried automatically, without requiring a retry policy
  - Fixed a rare timing issue that could cause a scheduled execution to be missed

- **Domains & DNS**
  - [Canary routing](https://docs.controlplane.com/guides/blue-green-deployments) — send a configurable percentage of traffic to a different set of workloads, including 0% and 100% for blue/green.

- **Monitoring & Observability**
  - Added native [Loki log export](https://docs.controlplane.com/external-logging/loki) for organization logs
  - Various log export improvements to prevent missed log records

- **Billing**
  - Added user-facing quota management to view account quotas and request changes

- **MCP Server** ([docs](https://docs.controlplane.com/mcp/overview))
  - Added managed Kubernetes (mk8s) tools
  - Added template catalog tools
  - Added Terraform export and conversion tools
  - Added distributed tracing tools to query and view traces
  - Added workload exec, replica listing, and replica stop tools
  - Streamlined the tool surface with toolset profiles for faster, clearer interactions
  - Safer destructive operations with confirmations tiered by blast radius

- **Marketplace Templates** ([catalog](https://docs.controlplane.com/template-catalog/overview))
  - Added [Supabase](https://docs.controlplane.com/template-catalog/templates/supabase), [Redpanda](https://docs.controlplane.com/template-catalog/templates/redpanda), [Weaviate](https://docs.controlplane.com/template-catalog/templates/weaviate), [Langfuse](https://docs.controlplane.com/template-catalog/templates/langfuse), [pgDog](https://docs.controlplane.com/template-catalog/templates/pgdog), and [Trivy](https://docs.controlplane.com/template-catalog/templates/cpln-trivy) templates
  - Updated the External Secrets Syncer through version 1.7.0
  - Marketplace templates now apply consistent tags to all resources they create

- **Web Console**
  - Added Virtual Machine (VM) workload support
  - Added domain [canary routing](https://docs.controlplane.com/guides/blue-green-deployments)
  - Added KubeVirt and node-local DNS managed Kubernetes add-ons
  - Added a link to KEDA logs
  - Added [GVC alias workload link](https://docs.controlplane.com/reference/gvc) configuration

- **CLI**
  - Released CLI version 3.11.0
  - Added the `mk8s health` command
  - Workload readiness is now determined from the workload health object

- **Terraform Provider** ([registry](https://registry.terraform.io/providers/controlplane-com/cpln/latest/docs))
  - Added VM workload type and KubeVirt managed Kubernetes add-on support
  - Added `location_query` support to the `cpln_gvc` resource for dynamic location selection
  - Extended validation for workload termination grace periods
  - Preserved user-chosen self-link formats across resources to avoid spurious plan diffs

- **Terraform Exporter**
  - Added VM workload type and KubeVirt managed Kubernetes add-on support
