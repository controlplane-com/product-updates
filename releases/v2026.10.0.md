# Release 2026.10.0

## Platform Updates - October 2026

- **Managed Kubernetes**
  - Added Kubernetes versions 1.36.5 and 1.35.9
  - New per-node-pool `maxPods` setting to control how many pods each node can run
  - Kata Containers add-on now supports shared volume sets on BYOK clusters
  - metrics add-on now supports per-collector drop filters

- **Workloads**
  - New `envFrom` support injects every key of a dictionary secret as environment variables
  - New optional `rolloutOptions.rolloutOnReferenceChange` setting rolls a workload when a referenced secret or identity changes, and records an event explaining the rollout
  - New [internal routing](https://docs.controlplane.com/reference/workload/general#internal-routing-and-location-failover) setting (`spec.networking.internal.routing`) lets internal `cpln.local` traffic fail over to healthy replicas in other locations (`gvcEndpoint`) or stay in the caller's location (`locationEndpoint`)
  - Deployment status now shows the identity version applied in each location
  - Envoy sidecar filters now support `header_mutation`

- **Volumes**
  - Volume shrink requests now show a clear validation error when the target size is below the volume set's initial capacity

- **Domains & DNS**
  - New [certificate generators](https://docs.controlplane.com/reference/certificategenerator) issue domain TLS certificates from your own ACME certificate authority, with HTTP-01 or DNS-01 challenges, including DNS-01 delegated to Control Plane

- **Monitoring & Observability**
  - New `container_last_terminated_reason` metric reports why each container last terminated
  - Syslog log export now includes additional log fields as RFC 5424 structured data
  - Metrics federation now supports compressed responses

- **MCP Server** ([docs](https://docs.controlplane.com/ai/mcp))
  - Added quota increase requests, template search, and secret prerequisite checks
  - `create_workload` and `update_workload` now support rollout, security, multi-zone, and per-location options
  - Identity, policy, and volume snapshot tools are now available in the core tool set
  - Managed Kubernetes cluster logs and metrics can be read through `get_workload_logs` and `query_metrics`
  - `run_volumeset_command` now supports copying volumes
  - Template release changes are now shown as a summary for easier review
  - Fixed `grant_cloud_access` validation and waits on reused roles

- **Marketplace Templates** ([catalog](https://docs.controlplane.com/template-catalog/overview))
  - **New templates**
    - [vLLM](https://docs.controlplane.com/template-catalog/templates/vllm) inference server on built-in or BYOK NVIDIA GPUs
    - [Neo4j](https://docs.controlplane.com/template-catalog/templates/neo4j) graph database
    - [OpenClaw](https://docs.controlplane.com/template-catalog/templates/openclaw)
  - **Updated templates**
    - New versions of 20+ templates, including Airflow, Ghost, SFTPGo, Tyk, SearXNG, Redis Cluster, and cpln-task-runner, read credentials from secrets, keeping passwords out of template values
    - [pgEdge](https://docs.controlplane.com/template-catalog/templates/pgedge) 3.0.0: PgBouncer pooling, permanent HAProxy failover, and one-command backup and restore
    - [TiDB](https://docs.controlplane.com/template-catalog/templates/tidb) 2.2.0: multi-location resilience, volume snapshots, inline ProxySQL, and backup and restore improvements
    - [Redis](https://docs.controlplane.com/template-catalog/templates/redis): dev mode (single replica, no Sentinel), a suspend switch, and a pre-existing secret option
    - Kafka 4.4.0: pre-existing secret option for every credential, and more reliable Kafka Connect startup
    - Temporal 2.0.0: Temporal 1.32.1, admin tools sidecar, and 1–5 replicas
    - Postgres Highly Available 2.8.0: `walLevel` setting, and logical replication slots are kept across failover
    - Debezium Server 1.3.0 and CDC Pipeline 1.1.x: improved change streaming setup for new installs
    - Open WebUI 1.3.0: admin from a prerequisite secret, public by default, and vLLM pairing
    - NATS 3.1.0: optional authentication from a prerequisite secret
    - Improved upgrades for templates that create their own GVC

- **Web Console**
  - New install wizards for the latest version of every marketplace template, with validation, prerequisite checks, and docs links
  - Added certificate generator support for domains
  - Improved template catalog search and categories
  - Virtual machine workload settings are grouped into one section with sub tabs
  - Added an advanced configuration dialog for domain routes
  - GVC and workload clones can now be reviewed before they run, with optional copying of GVC policies
  - List export can now include all, queried, or selected items
  - Revealed secret values can be copied without displaying them, and secret defaults can be prefilled from a create link
  - Managed Kubernetes node pools show their effective max pods
  - Cron schedules are described in local or UTC time
  - Menu favorites are now available across all of your orgs, and each browser tab stays on the org in its address
  - Improved the unsaved changes prompt, GVC export and clone, and onboarding, payment method, and invite flows

- **CLI**
  - Released [CLI version 3.18.0](https://docs.controlplane.com/cli-reference/release-notes)
  - `cpln stack` supports compose variable substitution, `.env` files, and `depends_on` (waiting for healthy dependencies and running one-time jobs first), matching docker compose
  - `cpln stack` accepts numeric and long syntax compose ports and the long syntax of `env_file`
  - Fixed Kubernetes Jobs converted by `cpln convert` running every minute; they now run only when started
  - Added `cpln volumeset copy` to copy volumes to another location or volume set
  - `cpln volumeset snapshot get` now shows creating and reverting stages
  - Fixed version comparison in `cpln upgrade`

- **Terraform Provider** ([docs](https://registry.terraform.io/providers/controlplane-com/cpln/latest/docs))
  - Released provider versions 1.2.33 and 1.2.34
  - Added KEDA `horizontal_pod_autoscaler_config`, `case_insensitive` domain routes, the mk8s Kata add-on, and BYOK maintainer environment settings
  - Added `certificate_generator_link` on domains, JSON values for remote write, and an optional Elastic logging path
  - Improved reliability with automatic retries for transient connection errors
  - Fixed TCP and gRPC probe port drift, DigitalOcean `reserved_ips`, and hyphens or underscores in custom GPU resources

- **Terraform Exporter**
  - Added a batch references mode
  - Output is now synced with provider 1.2.34 and formatted like `terraform fmt`
