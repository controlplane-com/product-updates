# Release 2026.07.0

## Platform Updates - July 2026

- **Workloads**
  - Fixed workload deploying status to only clear once the whole workload is ready
  - Removed a stale "Deployment is paused" message shown for BYOK workloads

- **Managed Kubernetes**
  - Added a new actuator setting for custom (BYOK) locations to override the default DNS resolver options applied to workload pods
  - Enforced a minimum number of local SSDs for supported GCP instance types

- **Volumes**
  - Volume shrink now shows more detailed progress in command status

- **Cron Jobs**
  - Fixed cron cleanup incorrectly deleting objects still in use

- **Domains & DNS**
  - Extended [canary routing](https://docs.controlplane.com/guides/blue-green-deployments) to TCP domain ports
  - Fixed several certificate issues, including subdomain CNAME domains not getting a certificate and repeated certificate failures not being surfaced to users
  - Fixed a bug affecting path-based and wildcard domain routing

- **Monitoring & Observability**
  - Increased dashboard alert retention to 3 months
  - Fixed an issue causing dashboard saves to fail

- **Billing**
  - Additional improvements to self-service quota increase requests, including more request detail and a fix for quotas with no approval boundary

- **Security & Reliability**
  - Fixed a bug preventing billing viewers from querying account-level audit records
  - Fixed issues that could cause in-progress operations to be incorrectly canceled or get stuck due to transient errors
  - Improved automatic recovery of workloads stuck in a Terminating state

- **MCP Server** ([docs](https://docs.controlplane.com/ai/mcp))
  - Added a [read-only toolset profile](https://docs.controlplane.com/ai/mcp) that exposes only non-destructive tools
  - Marked tag-overwriting and replica-stopping tools as destructive, so they now require confirmation
  - Added remote image build tools
  - Secret tools are now read-only, and the assistant can draft manifests for missing secrets
  - Improved validation for GVC and IP set locations
  - Removed the `workload_exec` tool

- **Marketplace Templates** ([catalog](https://docs.controlplane.com/template-catalog/overview))
  - **New templates**
    - [Prometheus](https://docs.controlplane.com/template-catalog/templates/prometheus)
    - [Thanos](https://docs.controlplane.com/template-catalog/templates/thanos)
    - [Mimir](https://docs.controlplane.com/template-catalog/templates/mimir)
    - [Metabase](https://docs.controlplane.com/template-catalog/templates/metabase)
    - [n8n](https://docs.controlplane.com/template-catalog/templates/n8n)
    - [Temporal](https://docs.controlplane.com/template-catalog/templates/temporal)
    - [Uptime Kuma](https://docs.controlplane.com/template-catalog/templates/uptime-kuma)
    - [Unleash](https://docs.controlplane.com/template-catalog/templates/unleash)
    - [Glitchtip](https://docs.controlplane.com/template-catalog/templates/glitchtip)
    - [TimescaleDB](https://docs.controlplane.com/template-catalog/templates/timescaledb)
    - [TimescaleDB HA](https://docs.controlplane.com/template-catalog/templates/timescaledb-highly-available)
    - [Vaultwarden](https://docs.controlplane.com/template-catalog/templates/vaultwarden)
    - [Umami](https://docs.controlplane.com/template-catalog/templates/umami)
    - [Gitea](https://docs.controlplane.com/template-catalog/templates/gitea)
    - [Open WebUI](https://docs.controlplane.com/template-catalog/templates/open-webui)
    - [LiteLLM](https://docs.controlplane.com/template-catalog/templates/litellm)
    - [Hermes Agent](https://docs.controlplane.com/template-catalog/templates/hermes-agent)
    - [SFTPGo](https://docs.controlplane.com/template-catalog/templates/sftpgo)
  - **Updated templates**
    - External Secrets Syncer: updated through version 2.0.0
    - Kafka: 4.1.0 adds rack-aware fetching to reduce cross-zone traffic, support for overriding log volume set names, and custom tags on connector workloads
    - Postgres HA: 2.4.1 fixes a boot-time DNS pinning issue by gating startup on Patroni endpoints answering
    - MySQL: fixed a backup configuration issue

- **Web Console**
  - Added cancelled and completed states to cron job execution history
  - Added canary routing support for TCP domain ports
  - Added shrink progress visuals for volumes
  - List and table views now persist filter and sort state in the URL, making them shareable and bookmarkable
  - Billing usage page now shows org name in tooltips and CSV export
  - Marketplace template pages now link directly to their documentation
  - Quota increase requests now show status in the Tasks UI
  - Cron job image override now uses a kind selector with prefill
  - Fixed several issues across identity pages, mk8s node pool validation, domain dry-run, logs query, and table/modal UI

- **CLI**
  - Released CLI version 3.15.0
  - Login now uses a device-code flow, with automatic browser opening for verification
  - Added [`cpln sandbox connect`](https://docs.controlplane.com/cli-reference/commands/sandbox) to connect to a running sandbox
  - Added [`--remote`](https://docs.controlplane.com/cli-reference/commands/image) to `cpln image build` for Docker-free, server-side builds
  - Added [`cpln quota request`](https://docs.controlplane.com/cli-reference/commands/quota) commands to submit, check, and list quota increase requests
  - Added `cpln version`, `cpln upgrade`, and `cpln metrics query` commands
  - Added `--name` to `cpln cron run` to target or create a specific cron workload
  - `logs --from` and `--to` now accept relative durations (e.g. `1h`)
  - Added automatic retry on transient proxy and connection errors during image push and pull
  - Improved Kubernetes converter handling of environment variables, firewall rules, workload types, and secrets
