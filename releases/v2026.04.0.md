# Release 2026.04.0

## Platform Updates - April 2026

- **Managed Kubernetes**
  - Added Kubernetes 1.35.3 support
  - Enabled in-place pod vertical scaling for Kubernetes 1.33+
  - Added option to use Cilium 1.19.2
  - Added node-upgrade event log entries
  - Added event log messages for AWS infrastructure deploys and instance group errors
  - CPLN Platform Add-on: shared volumes can be enabled in settings

- **Workloads**
  - Improved Capacity AI for stateful workloads
  - Fixed stale readiness for serverless workloads scaled to zero
  - Fixed a creation error during stateful workload delete and recreate
  - Fixed an issue where jobs could be deleted before they finished

- **Volumes**
  - Added a minimum cooldown period between volume expansions
  - Surfaced volume related events in the workload event log
  - Improved volume capacity reporting

- **Domains & DNS**
  - Added GVC geo-routing controls for disaster recover configurations: location routing tier, latency offset, and latency tolerance
  - Added a configurable port option for domain mirroring
  - Fixed an issue where mirrored domains status was modified more frequently than necessary

- **Networking**
  - Added optional IPv6 endpoints for some GCP locations, additional support in progress
  - Added optional Proxy Protocol support

- **CLI**
  - Released CLI version 3.10.1
  - Added pagination to the `logs` command to fetch results beyond the server limit
  - Added export support for proxy port 3128
  - Fixed `--arg` and `--header` dropping values that look like options
