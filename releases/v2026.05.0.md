# Release 2026.05.0

## Platform Updates - May 2026

- **MCP Server**
  - Released a major revision of the [Control Plane MCP Server](https://docs.controlplane.com/mcp/overview)

- **Managed Kubernetes**
  - Expanded Azure support, including additional locations and cloud access bindings
  - Added additional Linode Kubernetes versions
  - Updated the Headlamp Kubernetes dashboard
  - Added support for reverse wormhole proxy

- **Workloads**
  - Surfaced additional pod and autoscaling events, including scale-up warnings, in workload event logs
  - Fixed GVC-scoped commands when a location is removed from a GVC
  - Fixed pagination of workload executions

- **Volumes**
  - Resolved a volume binding issue that could, in rare conditions, prevent workloads from using the volume
  - Fixed zone selection when shrinking volumes
  - Volume related events now appear in the workload event log

- **Domains & DNS**
  - GVCs can now designate a workload to control DNS routing for the GVC endpoint
  - Surfaced certificate failures and clearer error messaging on domain status
  - Added certificate events to the domain event log

- **Networking**
  - Workload inbound "allow CIDR" lists now support up to 255 entries

- **Marketplace Templates**
  - Added [MongoDB cluster](https://docs.controlplane.com/template-catalog/templates/mongodb) template
  - Added Elasticsearch and Cassandra templates
  - Added 1Password Connect to the External Secrets Syncer template
  - Added Debezium and change-data-capture (CDC) pipeline templates
  - Added [Kafka 4.0.0](https://docs.controlplane.com/template-catalog/templates/kafka)
  - [Redis](https://docs.controlplane.com/template-catalog/templates/redis): configurable probe settings, lifecycle cleanup hooks, a metrics exporter, and improved replica resilience
  - [PostgreSQL HA](https://docs.controlplane.com/template-catalog/templates/postgres-highly-available): multi-datacenter support, PgBouncer integration, multizone support, and improved backups

- **Web Console**
  - Added resource groups
  - Added a What's New panel for platform updates
  - Log queries now support "not equals" and regular expressions
  - Improved list page performance with server-side querying and pagination
  - Added node pool refresh for AWS and GCP
  - Added copy buttons for domain DNS records
  - Added search to the template catalog and improved account list search
  - Improved workload and Kubernetes health views, including auto-updating health on release pages
  - List page deletions now confirm by name
  - Fixed audit trail pagination and various org creation and onboarding issues

- **CLI**
  - Released CLI version 3.10.2
