# Release 2026.09.0

## Platform Updates - September 2026

- **Managed Kubernetes**
  - Version upgrades now rollout to one node at a time, cordoning and draining each node before it is replaced
  - Added a Kata Containers add-on for managed and BYOK clusters
  - AWS: the EFS CSI role ARN is now optional and is created automatically when omitted
  - Cluster autoscaler scale-up failures are now surfaced as metrics and alerts

- **Workloads**
  - Internal communication between workloads on Managed and BYOK locations is now possible w/ new GVCs
  - New `cpln/skipGVCDomain` workload tag removes the public GVC subdomain while keeping internal (`cpln.local`) routing
  - Virtual machine replicas now show more detailed startup messages for scheduling, provisioning, and image import progress

- **Cron Jobs**
  - Failed cron runs now show more detailed failure messages
  - Cron runs stuck on an invalid or unpullable image now fail immediately

- **Volumes**
  - Volumes can now be copied between locations, or into another volume set or GVC, from a running or idle source

- **Domains & DNS**
  - Domain routes support a new `caseInsensitive` flag for case-insensitive prefix matching
  - Warning added when two GVC domains reuse the same TCP port on a shared load balancer

- **Networking**
  - Dedicated load balancers have an improved scheduling policy
  - Direct load balancer external health checks now probe the exposed port

- **Monitoring & Observability**
  - New built-in alerts for quota utilization above 80% and for pods requesting over 90% of the largest managed Kubernetes node's CPU or memory
  - Syslog log export now supports messages up to 32 KB (RFC 5424) instead of truncating at 2 KB
  - Added metrics for cron executions

- **Sign-in & Accounts**
  - Accounts can now be created from the CLI
  - Clearer messages when an email is already registered with a different sign-in method

- **MCP Server** ([docs](https://docs.controlplane.com/ai/mcp))
  - Added job tools and `list_orgs`, with the org defaulting from the sign-in grant
  - Secrets can now be deleted through the assistant
  - `get_trace` returns the newest traces first, supports method and request ID filters

- **Marketplace Templates** ([catalog](https://docs.controlplane.com/template-catalog/overview))
  - **New templates**
    - [Apache Spark](https://docs.controlplane.com/template-catalog/templates/spark) standalone cluster
  - **Updated templates**
    - [pgEdge](https://docs.controlplane.com/template-catalog/templates/pgedge): active/active routing with local-first defaults and per-location failover
    - [Hermes Agent](https://docs.controlplane.com/template-catalog/templates/hermes-agent): browser sidecar, external webhooks, OAuth for MCP servers, and optional WhatsApp support
    - NocoDB: new option to allow webhooks to services in the same GVC
    - Ghost: fixed admin login when SMTP is not configured
    - Twenty and ToolJet: fixed first-boot failures by waiting for Postgres to be ready
    - Listmonk: public links now resolve correctly
    - Kafka: fixed 3.x broker logs filling ephemeral storage
    - MinIO: updated image source to a new upstream image
    - Manticore: fixed earlier versions failing validation

- **Web Console**
  - Redesigned template catalog with categories, a popular section, a list view, and improved search
  - Helm releases can now be moved between GVCs, with confirmation of leftover resources
  - Added a copy volume action and copy progress to volume set pages
  - KEDA editor now supports HPA behavior and fallback settings with inline validation
  - Managed Kubernetes machine type browser can filter GCP machine types by zone, CPU platform, and local SSD count, and Hetzner images by architecture
  - Added the Kata Containers add-on switch to managed Kubernetes clusters
  - The main navigation can now be collapsed to an icon rail
  - Added custom expression columns to list tables, with export and import of column settings
  - Added a breadcrumb switcher to detail pages and a GVC activity indicator
  - Workload container and tab selections are now kept in the URL
  - Fixed volume set command actions, snapshot rows, and restore, and preserved volume set specs on save
  - Scale-to-zero is now validated per workload type

- **CLI**
  - Released CLI versions 3.17.0 through [3.17.2](https://docs.controlplane.com/cli-reference/release-notes)
  - Added `cpln profile create` as a standalone command
  - `cpln helm upgrade` and `rollback` now refuse to move a release out of a GVC unless `--delete-leftover-resources` is passed, and print the cleanup plan before making changes ([docs](https://docs.controlplane.com/guides/cpln-helm#moving-a-release-between-gvcs))
  - `cpln helm uninstall` only deletes empty GVCs
  - `--wait` and `--ready` no longer time out on workloads suspended in every location
  - `cpln workload cron get` now shows each execution's actual start and completion times
  - macOS installs now use tarballs for Homebrew

- **Terraform Provider** ([docs](https://registry.terraform.io/providers/controlplane-com/cpln/latest/docs))
  - Released provider version 1.2.32
  - Fixed domain inline route ordering and an omitted `tls` block
  - Fixed `cpln_domain_route` matching routes without a host, and port truncation on import
